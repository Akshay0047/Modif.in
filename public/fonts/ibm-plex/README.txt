IBM Plex Sans, Google Fonts v23 distribution

Source stylesheet:
https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600;700&display=swap
Retrieved 20 October 2026. Font files are unmodified WOFF2 subsets from the
fonts.gstatic.com URLs in that stylesheet. All six original script subsets
are retained; the Latin subset is preloaded and others load by unicode-range.

The variable font supports weights 100 through 700. Application typography
and the IBM Plex Sans family remain unchanged. Vite fingerprints the files
under src/assets/fonts/ for the production build.
